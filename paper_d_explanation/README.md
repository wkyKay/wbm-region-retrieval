# 区域J＋F的解释与评分证据遮蔽

论文进度维护在[论文实验证据总表](../doc/论文实验证据总表.md)。本入口完成D1–D4，沿用`add_a0p4_b0p25`及原运算顺序、区域、特征、联合J、贪心匹配和完整查询权重分母。它是对已有主方法的事后解释与诊断，不训练、不选参、不新增正式方法×split成绩。

## 固定设计

- D1/D2：普通与跨组合各37类首个固定查询×rank1/10/100，共222对。复原实际匹配、原始mask及C/T/A贡献，逐例核对原排名得分；代数分项另记录float32运算顺序带来的舍入残差。
- D3：预设普通exact成功、跨组合完整覆盖且含额外标签、跨组合部分覆盖、跨组合无覆盖四类。失败展示还要求完整合格图库中存在至少一个正覆盖候选，避免把图库无相关样本当成模型失败。先从固定样例池按query ID、rank、candidate ID选择；某类缺失时仅扩展到该协议全部原rank1，再缺失则报告缺失。图像只表达真实匹配，不赋予区域未经标注的缺陷语义。
- D4：两协议分别以原rank1为解释参考，所有7,199个查询重放基线；至少2个区域的7,161个查询进行策略比较。每次将一个查询区域对全部候选区域的评分行置零，保持原分母并重匹配、重排。38个单区域查询只进入基线审计。
- 高／低策略按对固定参考候选的实际加权贡献选区域，并列按原索引。随机策略枚举全部单区域遮蔽并平均结果指标，不平均分数后再排名。
- 面积近似匹配要求同query两个区域的sqrt(area)权重比不超过1.2，先选择log权重比最接近的一对、再以索引破并列，随后区分高低贡献。没有可比对的查询不进入此子集；不按结果改阈值。
- 普通报告P@10和Coverage-nDCG@10，跨组合报告Coverage-nDCG@10。均与同一诊断子集的未遮蔽结果比较，IDCG=0只从该nDCG均值中排除并报告有效查询数。另保存参考得分、名次和Top10保留情况。差值为遮蔽后减遮蔽前。

## 执行与封存

在持有原模型、缓存和完整排名的服务器，从仓库根目录和原PyTorch环境运行：

```bash
python -u -m paper_d_explanation.run --stage compute --workers 8
python -u -m paper_d_explanation.run --stage render --output-root results/<本轮目录>
```

计算阶段在实际启动时创建`results/<时间>__paper_d_explanation/`，保存冻结计划、科学源码及输入签名；原来源只读。绘图代码单独记录版本，以便完成视觉核验后统一封存。检查生成图后记录`figure_review.json`的实际审阅图片及哈希，再执行：

```bash
python -u -m paper_d_explanation.run --stage seal --output-root results/<本轮目录>
python -u -m paper_d_explanation.run --stage verify --output-root results/<本轮目录>
```

现有输出拒绝覆盖。计算失败保留目录，科学实现或设置变化另开运行。完成后作为原普通／跨组合主方法的支持材料纳入唯一来源清单，不把诊断子集登记成新的7,199查询正式成绩。
