# F 的区域 WBBS 评分

本包固定原 Top-4 区域、CNN 和外层匹配，只比较区域内部结构评分。目标是在保留区域来源与对应解释的条件下，验证点级最佳伙伴匹配能否改善跨组合检索。本轮已在独立目录`artificial/f_region_wbbs_20261121T143545+0800/`完成全部37项评价及根封存，独立分析已完成。valid主选仍为原区域J；当前原尺度区域WBBS没有提高预设的跨组合检索目标，不替换项目指定的 cc8 主方法。

公共协议、保存和登记规则见[项目说明](../doc/项目说明.md)，最终 test 比较维护在[消融实验](../doc/消融实验.md)。原基线来自[区域 J 与面积融合](../f_region_area_fusion/README.md)，WBBS 实现依据与复现边界见[原 WBBS 说明](../../compared_methods/methods/wbbs/README.md)。

## 固定区域与点描述

使用原 cc8 八连通、`min_area=5`、Top-4、三通道 52×52 窗口缩放至96×96，以及冻结的 h512 `best_nce`、seed2026。已有 h512、原始区域 mask、面积及 J 描述符按 dtype 和字节核对后复制；本轮不训练、不重新提取 CNN 特征、不扩展区域，也不加入上一轮的背景校准或拒配。

每张完整原图的全部缺陷点进行一次生产 tensor voting：`sigma_d=9`、`block_size=256`。stick/ball分别除以该图去噪前的通道最大值，零通道保持0；rho使用有效晶圆包围框中心及最远支持点半径归一化。按旧区域 mask 切取 `[stick, ball, rho]`，区域内部保持原图行优先顺序。

| 点集 | 固定规则 |
| --- | --- |
| 全部原始区域点 `all_points` | 保留原区域全部缺陷像素，点数等于原区域面积 |
| WBBS去噪点 `wbbs_denoised` | 使用整图原WBBS阈值0.32：仅在stick和ball都严格低于各自整图最大值×0.32时删除，再按旧区域mask取子集 |

不在区域内重新投票、归一化或设阈值，不填正常像素，不改变区域mask或面积。去噪后区域点集可为空；重复描述符保留原行与点数。原图坐标、全图点索引和全局keep子集均保存供追溯。

## 区域评分与固定网格

原区域J基线保持既有算术：

```text
C = clip(cos(hq, hc), 0, 1)
T = exp(-0.5 * Hellinger(Jq, Jc))
A = exp(-0.5 * abs(log(rq) - log(rc)) / 1.5)
S_J = 0.75 * (0.4*C + 0.6*T) + 0.25*A
```

J为区域全部原始点的128维联合软直方图，r为原区域缺陷面积／有效晶圆面积。新点描述的列顺序换成`[rho, stick, ball]`后逐区域重建 J，与旧`joint_all`在绝对误差`1e-14`内一致；旧存储值仍原样复制。

区域点集之间按三维平方欧氏距离求双向最近邻，`mu=1`。只有互为最近邻的点对计为最佳伙伴；同距离取对方原始顺序的首个点。设最佳伙伴数为B，完整点集大小为N、M：

```text
W_p = B / min(N, M) * exp(-p * abs(N-M) / 2061)
任一集合为空: W_p = 0
S_W = 0.75 * (a*C + (1-a)*W_p) + 0.25*A
```

| 维度 | 冻结值 |
| --- | --- |
| 点集 | 全部原始区域点、WBBS全图去噪子集 |
| 数量差惩罚p | 0（仅最佳伙伴比例）、5（原WBBS惩罚） |
| CNN内部权重a | 0.25、0.4、0.6 |
| 面积外层权重 | 0.25 |

共12个区域WBBS配置，加原J基线共13个区域方案。内部去重若用于精确搜索加速，只保留重复描述符的首行进行匹配；B的计数规则、归一化分母N/M及数量差惩罚仍按完整点数，不能把去重后的数量代入。空集和重复描述符可能使自相似度小于1，保存诊断，不为得到1而修改原WBBS规则。

外层继续按区域对分数降序做单向一对一贪心匹配，并以查询全部已选区域的`sqrt(area)`权重平均；未匹配区域计0，候选额外区域不直接扣分。固定a=0.4的四项与J基线保持CNN／面积系数一致，用于区分点集与惩罚的影响；其他a同时改变CNN／结构权重，不称单因素结构替换。

沿用原始尺度，不新增分布标定。区域`T=exp(-0.5*Hellinger)`的范围为`[exp(-0.5),1]`，区域W为`[0,1]`；相同a控制融合系数，并不保证两种结构分数的实际贡献或变化幅度相同。结论只覆盖这份固定原尺度网格。

## 选择规则与评价
