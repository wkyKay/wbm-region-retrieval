# F 的区域 WBBS 评分

本包固定原 Top-4 区域、CNN 和外层匹配，只比较区域内部结构评分。目标是在保留区域来源与对应解释的条件下，验证点级最佳伙伴匹配能否改善跨组合检索。当前处于实现与验证阶段，尚无本轮正式成绩；不替换项目指定的 cc8 主方法。

公共协议、保存和登记规则见[项目说明](../doc/项目说明.md)，最终 test 比较维护在[消融实验](../doc/消融实验.md)。原基线来自[区域 J 与面积融合](../f_region_area_fusion/README.md)，WBBS 实现依据与复现边界见[原 WBBS 说明](../../compared_methods/methods/wbbs/README.md)。

## 固定区域与点描述

使用原 cc8 八连通、`min_area=5`、Top-4、三通道 52×52 窗口缩放至96×96，以及冻结的 h512 `best_nce`、seed2026。已有 h512、原始区域 mask、面积及 J 描述符按 dtype 和字节核对后复制；本轮不训练、不重新提取 CNN 特征、不扩展区域，也不加入上一轮的背景校准或拒配。

每张完整原图的全部缺陷点进行一次生产 tensor voting：`sigma_d=9`、`block_size=256`。stick/ball分别除以该图去噪前的通道最大值，零通道保持0；rho使用有效晶圆包围框中心及最远支持点半径归一化。按旧区域 mask 切取 `[stick, ball, rho]`，区域内部保持原图行优先顺序。

| 点集 | 固定规则 |
| --- | --- |
| 全部原始区域点 `all_points` | 保留原区域全部缺陷像素，点数等于原区域面积 |
| WBBS去噪点 `wbbs_denoised` | 使用整图原WBBS阈值0.32：仅在stick和ball都严格低于各自整图最大值×0.32时删除，再按旧区域mask取子集 |

不在区域内重新投票、归一化或设阈值，不填正常像素，不改变区域mask或面积。去噪后区域点集可为空；重复描述符保留原行与点数。原图坐标、全图点索引和全局keep子集均保存供追溯。

## 区域评分与固定网格

原区域J基线保持既有算术：

```text
C = clip(cos(hq, hc), 0, 1)
T = exp(-0.5 * Hellinger(Jq, Jc))
A = exp(-0.5 * abs(log(rq) - log(rc)) / 1.5)
S_J = 0.75 * (0.4*C + 0.6*T) + 0.25*A
```

J为区域全部原始点的128维联合软直方图，r为原区域缺陷面积／有效晶圆面积。新点描述的列顺序换成`[rho, stick, ball]`后逐区域重建 J，与旧`joint_all`在绝对误差`1e-14`内一致；旧存储值仍原样复制。

区域点集之间按三维平方欧氏距离求双向最近邻，`mu=1`。只有互为最近邻的点对计为最佳伙伴；同距离取对方原始顺序的首个点。设最佳伙伴数为B，完整点集大小为N、M：

```text
W_p = B / min(N, M) * exp(-p * abs(N-M) / 2061)
任一集合为空: W_p = 0
S_W = 0.75 * (a*C + (1-a)*W_p) + 0.25*A
```

| 维度 | 冻结值 |
| --- | --- |
| 点集 | 全部原始区域点、WBBS全图去噪子集 |
| 数量差惩罚p | 0（仅最佳伙伴比例）、5（原WBBS惩罚） |
| CNN内部权重a | 0.25、0.4、0.6 |
| 面积外层权重 | 0.25 |

共12个区域WBBS配置，加原J基线共13个区域方案。内部去重若用于精确搜索加速，只保留重复描述符的首行进行匹配；B的计数规则、归一化分母N/M及数量差惩罚仍按完整点数，不能把去重后的数量代入。空集和重复描述符可能使自相似度小于1，保存诊断，不为得到1而修改原WBBS规则。

外层继续按区域对分数降序做单向一对一贪心匹配，并以查询全部已选区域的`sqrt(area)`权重平均；未匹配区域计0，候选额外区域不直接扣分。固定a=0.4的四项与J基线保持CNN／面积系数一致，用于区分点集与惩罚的影响；其他a同时改变CNN／结构权重，不称单因素结构替换。

## 选择规则与评价

普通valid评价13个区域方案，保留exact和coverage。跨组合valid评价上述13项及独立整图WBBS基准，共14项；整图WBBS只用于比较，不参与区域主方案选择。唯一主方案在13个区域方案中按**跨组合valid总体Coverage-nDCG@10**选择；同时固定最佳区域WBBS配置。

差值不超过`1e-12`视为并列，依次优先原J、CNN权重最接近0.4、全部原始区域点、较小数量差惩罚、方案名。只有27项valid评价完整封存后才能冻结选择并进入test；不依据ordinary valid P@10或后续test改选。

test固定评价四个a=0.4对照，再加最佳区域WBBS配置，去重后为4或5项，各自完成普通与跨组合test。唯一主选可能仍为原J；被要求运行的四项对照不自动成为主选。原J与整图WBBS历史test报告只按同协议引用，不为比较重复登记。test不改变点集、权重、惩罚、模型、匹配或参数。

| 协议 | valid | test |
| --- | --- | --- |
| 普通完整候选 | 500 query，3,599 gallery，共1,799,000个非自身配对 | 7,199 query/gallery，共51,818,402个非自身配对 |
| 跨组合完整候选 | 另排除完整标签组合相同候选，共1,750,095对；每query3,499–3,585候选 | 同规则，共50,395,860对；每query6,999–7,170候选 |

跨组合排名从完整候选分数重新产生，不过滤旧Top-500。保持原六项coverage指标和K=1/5/10/20/50/100/500，不新增覆盖等级指标。跨组合valid的nDCG有效query为484，FullCoverage Recall/AP为428；test分别为7,000与6,200。普通和跨组合分表，保留总体、类别宏平均、单／混合及标签数量分组；无定义值不填0。

## 运行入口

在原NumPy／PyTorch环境、仓库根目录运行；本轮不需要CUDA推理。保持三个线程变量为1，以复现既有数值：

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1
export PYTHONDONTWRITEBYTECODE=1
python -m unittest discover -s f_region_wbbs/tests -v
python -m f_region_wbbs.run --dry-run
python -u -m f_region_wbbs.run --stage all \
  --prepare-workers 4 --workers 48 --score-workers 16 --eval-workers 8
```

`--stage valid`只完成valid与冻结选择；`--stage test --resume-root artificial/<本轮目录>`只接受同一根目录已封存的完整选择。正式输出使用新的真实时间目录；签名一致的已完成缓存可只读复用，不覆盖不完整目标。来源、源码或科学设置变化须新目录。独立时间目录的valid性能预检显示，48个计数worker相比24个的吞吐提高约29.3%，据此采用48个；预检产物不登记为正式结果。仅按预检吞吐外推，valid/test计数阶段约6.5／94分钟，实际还包括I/O及其他阶段，不作为完成时间承诺。不得为加速减少正式候选或抽样点集。

## 缓存、验证与边界

`cache/<split>/`保留原区域数组、h512和mask；两种点集分别保存`offsets/descriptors/coordinates.npy`，可按路径只读mmap加载。`region_trace.jsonl`追踪每区原图像素与全图点索引，`audit.json`记录点数、空集、单点、重复描述符及原字节一致性。

区域J与几何重建覆盖全部区域；固定每37类首个query另调用原`encode_wafer`核对全图去噪描述及区域子集。这些独立审计会额外投票，区别于每图一次的生产准备。最佳伙伴、内外层公式另由独立实现抽查；所有query的完整缓存排名与指标另行核验，不把抽查称为全量独立区域公式计算。

整图WBBS的cross-valid基准复用旧`fgw_grid_20261119T200653+0800/component_cache/valid`完整float64分数。读取其完成文件、原始ID、来源签名与哈希，再复制到本轮独立分数缓存；自身格仅按新缓存约定保存0，永不进入候选排名，所有非自身分数保持完全一致。

旧源码、NPZ、协议、模型、区域缓存、排名和报告只读。本轮属于查看既往test后的研究，虽然本轮参数在valid冻结，不能据此声称整个研究从未接触test。区域选择规则、点对应与分数分解提供可追溯解释，不等于每个区域的语义标签或因果必要性证明；区域WBBS是对已有点匹配方法的局部适配，不宣称重新发明WBBS。
