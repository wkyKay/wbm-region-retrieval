# T-Linkage 多直线像素适配说明

本次显示名称应为 **T-Linkage (line), Python port / 晶圆像素适配**。它不是作者发布的 MixedWM38 模型，也不是已在 MixedWM38 证明有效的缺陷语义分割器。

## 依据与作者代码

- Magri, L. & Fusiello, A., *T-Linkage: A Continuous Relaxation of J-Linkage for Multi-Model Fitting*, CVPR 2014, pp. 3954-3961。
- 原论文：<https://fusiello.github.io/papers/cvpr14.pdf>
- 作者项目：<https://fusiello.github.io/demo/jlk/index.html>
- 作者 MATLAB 压缩包：<https://fusiello.github.io/demo/jlk/Tlinkage.zip>，于 2026-11-11 下载。原 ZIP、使用到的未修改 MATLAB 文件和 SHA-256 位于 `author/tlinkage/`。
- 当前环境没有 MATLAB / Octave，因此实际计算使用 Python 移植。没有声称直接运行作者 MATLAB 或与 MATLAB 在同一随机序列上逐值一致。

## 与原论文一致的核心

1. 原始缺陷点二维坐标作为观测；两点确定一个直线假设。无需类别标签、类别数、像素标注或模型训练。
2. 原文 Eq. (2)：`PF=exp(-residual/tau)`，在 `residual >= 5*tau` 截断为 0；残差是点到无限直线的垂直距离。
3. 原文 Eq. (5)：Tanimoto 距离 `1 - dot(p,q)/(dot(p,p)+dot(q,q)-dot(p,q))`。
4. 原文 Eq. (4) / Algorithm 1：每点独立初始化；每次合并全局最近的两个簇，簇 PF 取逐元素最小值；所有距离达到 1 时停止。输出簇数自动决定。
5. 原作者 `demo.m` 使用 `5*N` 个候选最小点集；本适配保留此数量。对重复的无序点对保留最后一次，与作者去重逻辑相同。
6. 每个保留簇做总最小二乘直线拟合，仅用于诊断；没有根据拟合线重新吸收、删去或补全区域像素。

Python 使用缓存每行最小值的堆实现全局贪心合并，只是计算优化，不使用近似近邻、限步聚类或提前固定簇数。初始 PF 内积用稀疏矩阵加速；后续合并只访问非零 PF 维度。

## 本次明确的适配参数

| 项目 | 本次设置 | 依据 |
|---|---|---|
| 坐标 | 原图 row / column，单位为像素 | 晶圆适配 |
| 模型族 | 只有直线 | 作者提供的 `line` 模型；所有 38 类一致，不按标签切换 |
| 采样 | 第一端点循环遍历全部点，另一端点均匀选择其他点；seed=2026 | 作者 demo 的循环首点思路；使用正确均匀的第二端点抽样 |
| 候选数 | 去重前 `5*N` | 作者 demo |
| PF 硬截断 epsilon | 2.5 px，即 tau=0.5 px | 本次统一像素尺度约定；不是论文给出的 MixedWM38 参数 |
| 预处理 | 无中值、形态学或类别相关去噪 | 保持本次单独检查几何分解能力 |
| 输出 | 原始 `raw==2` 像素的互斥簇编号，0 为未分配 | 原簇标签回填原图；不画整条拟合直线充当 mask |

作者 `mssUniform.m` 的累积分布写法使第二端点无法选中 MATLAB 索引 1。本移植按论文的均匀抽样意图纠正该采样偏差，并使用 NumPy RNG；因此不宣称复现 MATLAB 的随机序列。数值距离完全相同时按原始点索引确定顺序，属于实现约定。

## 离群点处理的重要区别

原文 §2.3 描述了二项概率检验与簇大小跳变相结合的策略；作者下载包的 `outlier_rejection_card.m` 注释明确说概率策略代码尚未提供。

本次 **移植作者 demo 实际调用的 `outlier_rejection_card.m`**：按簇大小排序，加入大小为 2 的虚拟簇，寻找最大大小跳变，删掉较小一侧。保留原作者“若最大跳变仅留下一个模型，则换用次大跳变”的分支，因此它带有至少两个模型的倾向。这会影响单模式或 Normal 的结果，不能隐藏这一限制。每图诊断包含该分支是否触发、所有簇大小和删去的簇编号。

本次没有用类别标签选择簇数，也没有以类别标签或人工分割结果调参。后续共同的 F 面积 >=5 / Top-4 显示属于单独的输出预算，不属于 T-Linkage 原算法。

## 应如何解读结果

- 线型模式即使在原图连通，也可以按照共同直线模型分开；一个区域不要求 4/8 连通。
- 交叉点只能归属一个簇；本次不增加共享交点或曲线补全规则。
- 宽圆环、不规则块状、Near-full 等不符合“多条直线”的模型假设，可能被切成多条带或产生碎区。该失败应原样显示，不按类别使用备用方法。
- 噪声也可能偶然形成较大的线性点簇；作者大小跳变过滤不保证删除所有噪声。
- 只适合样例目视审查，不代表原论文在 MixedWM38 上的复现性能或正式检索结论。
