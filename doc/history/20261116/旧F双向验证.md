# F 双向评分验证（2026-11-11）

## 结论

固定 F best_nce 后，仅将原方向评分替换为双向调和平均，valid 总体小幅改善；
主要收益来自单缺陷查询，混合缺陷的 mAP@100 几乎不变。当前证据不支持将它视为
解决 F 与 WBBS 差距的主要改进，也不支持宣称混合缺陷检索已显著提升。
未重训、未执行 test、未替换 F 默认评分、未覆盖旧产物。

## 方法与协议

- 原模型：远程 `/data/wangkaiyan2024/wbm-region-retrieval/artifacts/formal_f_exact_20261109_132219/run/seed_2026/F/best_nce.pt`，epoch 100。
- 500 个冻结 valid query，每个对完整 valid gallery 除自身的 3,598 个候选评分。
- 同一份归一化 h512 特征用于原评分和双向评分；所有 CNN 参数、区域、面积权重、阈值及同分规则不变。
- 分别独立执行原贪心匹配，得到 `a=S(Q,C)`、`b=S(C,Q)`；新分数为 `2*a*b/(a+b)`。
  两方向都为零时返回零，不用 epsilon 引入数值偏差。反方向重新排序，保持其自身的源/目标索引同分规则。
- 保留 exact_v1 完整标签组合相关性和完整池 AP/Recall 分母，不减少候选。
- SHA 核查原 checkpoint 身份、输入规格、valid 缓存及池文件；核对 query/gallery 与本仓库冻结清单一致。

| 指标 | 原 F | 双向 F | 差值 |
|---|---:|---:|---:|

| Precision@5 | 0.324800 | 0.322800 | -0.002000 |
| Precision@10 | 0.286200 | 0.291600 | +0.005400 |

| mAP@100 | 0.067040 | 0.070066 | +0.003027 |
| mAP@500 | 0.108792 | 0.113146 | +0.004354 |

这些是 valid 结果，不能与上次讨论的 WBBS/F test 数字直接比较。

## 分组与不确定性

| 分组 | query 数 | 原 mAP@100 | 双向 mAP@100 | 差值的配对 bootstrap 95% 区间 |
|---|---:|---:|---:|---|
| 总体 | 500 | 0.067040 | 0.070066 | [0.001080, 0.005672] |
| 单缺陷 | 98 | 0.145276 | 0.160655 | [0.006655, 0.027505] |
| 混合缺陷 | 402 | 0.047967 | 0.047982 | [-0.001038, 0.001010] |

总体 Hit@1 差值区间为 [0, 0.052]；Precision@10 为 [-0.001600, 0.013400]；
mAP@10 为 [-0.000319, 0.001431]。前列指标改善仍存在不确定性。
配对区间对同一查询的指标差进行 2,000 次有放回抽样，seed=2026；它描述当前验证查询的
抽样不确定性，不包含训练随机性，也没有多重比较校正。

单缺陷查询 Precision@10 从 0.436735 到 0.462245，混合缺陷从 0.249502 到 0.250000。
该现象与“候选额外区域扣分有助于部分单缺陷查询”的假设相容，但本实验没有统计错误候选的
真实标签包含关系，不能将具体原因视为已证实。

## 验证与产物

- 新评分的正向结果与原 `batched_map_scores` 在全部 valid 配对上最大绝对误差为 **0**。
- 重算原 F 的全部 28 个总体指标与原保存的 `valid/best_nce/metrics.json` 差值均为 **0**。
