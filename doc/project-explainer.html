01

项目背景：把晶圆理解为一张测试地图

先理解“哪些位置的芯片没通过测试”，就能理解本项目的数据和任务。

从制造到数据，只需要掌握这四步

① 在圆片上制造芯片晶圆：承载许多小芯片的硅片
Die：其中的一颗芯片单元
② 逐颗进行电测试测试探针检查电性能
记录通过与未通过的位置
③ 生成晶圆图 WBM将测试结果排回原位置
得到可供程序处理的二维网格
④ 检索相似历史图为工程师提供可参考的案例
辅助后续排查

制造流程为教学简化。WBM 是电测试状态图，不是显微镜拍摄的表面照片；项目从已有 WBM 数据开始，不控制制造或测试设备。[1]

数据是什么？

每张图是 52×52 数组。0 表示图中空白位置，1 表示通过电测试，2 表示未通过。本项目以 raw == 2 提取缺陷；少量值 3 不自动当作缺陷。

图案有什么用？

未通过测试的点可能聚成中心团、环、边缘带或线状图案。相近的分布能提供排查线索，但形状相似不能直接证明故障原因相同。

为什么看局部？

一张图可能同时出现多种图案。整图外观不同，仍可能共享有价值的局部缺陷，因此希望逐块比较，再汇总到晶圆层面。

用真实样本认识缺陷地图

常用图案名称包括中心团、环形、边缘局部、边缘环带、局部块、随机散点、线状划痕和接近全片。下面展示项目自带 300 张子集的八个单标签列样本；标题描述外观，列号为原数组的零基索引。这些不是检索结果，也不是区域标注真值。

通过测试的芯片未通过测试的芯片图中空白

映射核对提示：当前 README 把标签列5/6/7依次命名为 random / scratch / near-full，但所选样本呈现高覆盖、散点和密集纹理，与该名称顺序存在疑点。本页不擅自重定类别，仅保留列号和外观说明；正式逐类解读前需核验名称映射。包含率本身按标签列集合计算。

Mixed-WM38 有 38 种组合类型：正常、8 种单一缺陷和 29 种混合缺陷。项目用 8 维 multi-hot 标签表示“哪些基本类型存在”。数据来源包含实际采集与为平衡类别而生成的样本。[1]

检索问题：候选图是否“包含了我关心的缺陷”？

例如查询图包含“环形＋局部块状”，候选图包含这两类并额外有“线状”，仍然是完整覆盖。反过来查询时，就缺少“线状”。

任务输出是一份历史晶圆排序，以及可查看的区域匹配。它不直接输出工艺根因；当前也没有区域级真值标注来逐条证明匹配正确。

2.2 一张图如何变成若干区域

取出缺陷像素二值化：raw == 2
仅保留未通过测试的位置
找 8 连通域上下左右或斜对角相邻
就视为同一块连通区域
筛选区域至少 5 个缺陷像素
按面积取最大的 4 块
标准化小图每块单独裁剪、补成方形
主配置加边距后缩放为 96×96
“连通的一块”不一定等于“一种缺陷”：一个类别可能分散成多块，两个类别也可能连成一块。top4 是保留最多四个连通区域，不是识别四种缺陷；过滤和截取可能丢失小区域。

2.3 不给区域标类别，如何训练？

把同一区域的两个视图当作同一个实例：原图与轻微变化后的图，应该在表示空间中保持一致；同时与记忆库中的其他区域区分开。

原始分支
区域小图 x完整保留原始区域
共享编码器ResNet-18 → h512
线性投影512 → 128 维
增强分支
区域变体 x′主实验：轻度开运算＋直角旋转
同一编码器共享全部参数
同一投影头输出 128 维
两分支各自对比 该区域的历史记忆向量 与 5,000 个负样本 → 平均 NCE 损失 → 更新网络；原始视图输出用于更新记忆库。

memory bank 可以理解为“每个训练区域的一份近期特征记录”；NCE 让对应实例比分配到的负样本更接近。负样本有放回采样，可能重复，也可能包含外观相似但属于另一实例的区域。

检索时仅使用编码器输出的 512 维 h 特征，不用 128 维投影头，也不再执行开运算。训练阶段的辅助结构不会全部进入检索路径。
轻度开运算，用直白的话怎么讲？

先收缩、再扩展缺陷像素，尝试去掉细小毛边。主配置以 50% 概率在标准化的 96×96 增强图上尝试一次；若变空或剩余前景少于 80%，退回原图，再做 0°、90°、180° 或 270° 旋转。它不改连通域提取、不改原始分支，也不保证每次都保持类别语义。

2.4 从区域相似度到晶圆得分

S(Q,C) = Σ[已匹配查询区域的 √面积 × 区域相似度] / Σ[所有查询区域的 √面积]
例：S(Q,C) = (3 × 0.9 + 2 × 0.8) / (3 + 2) = 0.86

区域之间如何比较

主方法计算 h512 的余弦相似度，并把负数截为 0。Zernike 基线将欧氏距离转成相似度。

遗漏与额外的区别

未匹配的查询区域仍计入分母，拉低得分；候选中未被使用的额外区域没有直接惩罚。无有效区域的图得分为 0。

最终怎样排序

对每个候选计算 S(Q,C)，降序排列。正式评分仅使用形状；位置、尺度只用于元数据和补充示例。

03

实验设计：回答三个不同的问题

主实验比较检索路线，消融实验定位改动作用，诊断实验检查模型是否真的从训练中获益。

3.1 固定数据，分开训练、选型与最终测试

本地原始数据记载为 38,015 张图；冻结协议使用其中 37,015 张非空标签图。下列数量已从当前 CSV 清单重新核对。

训练 25,910约 70% · 更新模型
3,700验证 10%
测试 7,405约 20% · 最终评价

正式测试：2,000 × 1,000

固定 2,000 个 test 查询，每个配 1,000 个不重复的 test 候选，排除自身。三类方法面对相同问题，共涉及 200 万个有方向的查询—候选对。

消融选型：500 × 1,000

valid 内固定 500 个查询，每个 1,000 个候选，采样不使用标签。第 1、5、10……100 轮进行检索评价；评价和选型会使用 valid 标签。

正式 test 候选清单来自历史的标签分层采样。因此分数描述的是这个固定候选池，不能直接当作全历史数据库的检索表现。valid/test 不参与梯度更新或 memory bank 更新。

百分比限制的是“可使用标签的训练晶圆数”，不是训练 pair 比例；按标签组合分层并形成嵌套子集，实际使用比例单独记录。三个预算均另外使用 valid 中固定 10,000 个有标签 pair 选模型。

学习模型均从同 seed 随机初始化；主实验采用相同编码器结构和初始化、100 轮、SGD 与余弦学习率调度。局部方法按区域训练，监督方法每轮采样 50,000 个有序整图 pair，故训练样本与计算量并不完全相同。监督参考也不是预设的性能上界。
主实验的关键参数

区域至少 5 像素、top4、输入 96×96、编码 512 维。局部训练头 128 维，NCE 温度 0.07，负样本 5,000 个有放回抽样，memory 动量 0.5。SGD 学习率 0.01、momentum 0.9、weight decay 0.001，batch 256，100 轮且不早停。主实验局部模型按最低 valid NCE 选 best.pt，监督模型按最低 valid pair loss 选择。

3.4 如何评价“找得好不好”

标签相关性 R(Q,C) = |查询标签 ∩ 候选标签| / |查询标签|

前面排得对不对

ContainmentNDCG@10：覆盖更多查询标签的候选，是否排在前十名的靠前位置？越高越好。

能否找到完整案例

FullCoverageHit@K：前 K 名中是否至少有一张完整覆盖查询标签？与 Recall“找回所有完整覆盖正例的比例”不同。

整个列表怎么样

mAP_full：综合整个候选列表中完整覆盖样本的排名；MRR_full 关注第一个完整覆盖样本的位置。

K 取 1、5、10、20；另报 MeanContainment、FullCoveragePrecision/Recall。按相同查询做配对 bootstrap，正式配置 1,000 次，报告 95% 区间；这不替代多训练 seed 的稳定性检查，也不消除选模型带来的偏差。

诊断实验与评价边界
  • 分 all / single / mixed 观察，避免总体均值掩盖混合缺陷问题。
  • 比较训练后与同架构 random，确认训练是否确实产生收益。
  • 诊断 h512 与 z128、best 与 last，区分训练损失最优和检索最优。
  • 单标签 top1 实验只在推理时保留最大区域，复用历史模型，不重新训练。
  • 候选池没有完整覆盖正例时，相关 Recall/Hit/AP/MRR 记为缺失并从对应均值排除，同时报告有效数量。
  • 晶圆标签只监督整体相关性，不能直接评价每条区域连线是否正确。

从整图分类改为局部区域检索；通过查询侧聚合表达方向性，允许候选包含额外缺陷。

训练层面的改动

工程层面的改动

这些是基于当前实现归纳的适配，不等同于原论文复现，也不构成“所有设计都首次提出”的新颖性声明。模型结构与优化设置的沿用不代表原论文的分类成绩可以直接作为本项目检索成绩的对照。

同查询侧聚合
比较 Zernike 与 proposed 时，共用区域提取和外层匹配，只改变区域表示与相似度计算。这样能更集中地观察“手工形状特征”和“学习形状特征”的差异；但两类分数的数值分布并不相同。

本项目没有复现原论文完整识别实验；47 维、离散归一化、距离映射及外层检索是项目的实现选择。它们属于适配，不应直接称为对 Zernike 理论本身的改进。

4.3 整图监督参考：项目自建的有方向对照

当前代码未给这套评分头标注独立的对比论文来源。准确的讲法是：复用同一编码器架构，项目自行构建有方向的整图监督评分器。

整图 Q 与 C各自二值化、补方
缩放到 96×96
共享编码器各输出 512 维特征
并归一化
有顺序地组合[q, c, q⊙c, q−c]
共 2,048 维
MLP → sigmoid预测标签包含率
用 MSE 训练

为什么不直接用整图余弦？

余弦相似度满足 cosine(q,c)=cosine(c,q)，但包含关系有方向。有顺序的输入和差值允许评分头学到 Q→C 与 C→Q 的差别。

它与主方法比较什么？

整图监督由标签教模型打分；局部方法用自监督学习区域，再按规则聚合。两者代表不同信息条件下的路线，不能视作只改一个组件的消融。

讲解时可以用这一段收束

本项目把晶圆测试图中的连通缺陷块当作可比较的对象，用自监督学习得到区域特征，再通过一对一匹配回答“候选是否覆盖查询”的问题。实验先比较数学形状特征、局部自监督和整图监督三条路线，再通过 A～F 拆解输入、增强与网络步幅的影响。当前已有实现与小规模运行验证，性能是否提升仍要由统一协议下的正式实验回答。
