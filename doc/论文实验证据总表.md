# 论文实验证据总表

最后核验：**2026-11-21（Asia/Shanghai）**。本表是本篇 ACAI 论文的唯一实验证据进度表；后续直接更新对应行，不另建日期版清单。围绕两条贡献：**结构增强的区域检索框架**、**与实际评分一致的区域匹配及得分解释**。这是本论文的工作清单，不是会议规定的实验数量要求。

**论文主方法是区域 J＋F**，采用原 valid 第一项 `add_a0p4_b0p25`：

```text
s = 0.75*(0.4*C+0.6*T)+0.25*A
  = 0.30*C+0.45*T+0.25*A
T = exp(-0.5*Hellinger(Jq,Jc))
```

固定 cc8、min_area=5、Top-4、h512、best_nce、seed=2026、贪心一对一及查询 sqrt(area) 聚合。J 是完整原图投票后按原始区域全部缺陷点汇总的128维联合分布，A为相对面积相似度，不是旧B1角向项。旧F、B1及整图J保留原运行身份，不因论文定位而重标。

**状态说明：**“已具备”指有可追溯的完成证据；“部分具备”只覆盖所列范围；“待完成”指当前论文所需设置尚缺正式证据。**实验状态与入稿状态分开**：已有JSON不等于已有论文插图，已计算结果不等于已写入中英文稿。本次入稿核对基准为论文仓库中英文版本 `1143390`；后续更新入稿状态时同步更新该版本。

普通检索报告exact／coverage，跨组合只报告coverage，两者分表。正文K=1/5/10/20/50/100；历史@500已计算并保留，不混作@100。新增消融在valid运行前冻结全部变体；valid用于实现／协议核验，之后评价全部预设变体，不按表现淘汰消融、不用test重选主配方。已有结果设置一致时核验复用，不重训CNN或重跑六种外部方法。
