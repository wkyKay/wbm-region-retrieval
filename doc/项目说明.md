## 实验设计

主方法为 **F：cc8 八连通＋径向位置＋相对面积**。从原图缺陷像素提取八连通区域，去掉面积小于 5 的区域，最多保留最大的 4 个。以区域中心取固定 52×52 窗口，缩放到 96×96；三通道分别表示所有缺陷、目标区域和有效晶圆。

ResNet18 首层步长为 1，提取 h512；自监督 NCE 训练 100 epoch，seed=2026，投影维度 128，检索不用投影头。冻结使用 `best_nce`；训练有四种直角旋转，正式推断没有随机增强或四旋转平均。加入几何评分不重训、不重新选模。

```text
s = clip(cos(hq,hc),0,1) × exp(-D_radial)
    × (0.85 + 0.15 × exp(-D_area/1.5))
D_radial = sum(abs(CDFq-CDFc))/16
D_area = 0.5 × abs(log(rq/rc))
r = 区域原始缺陷像素数 / 有效晶圆像素数
```

径向项是归一化半径的 16 格累积分布，不是绝对二维坐标。有效晶圆取原像素值 1 或 2，中心取其包围框中心，半径取最远有效像素距离。全部几何量从完整原始 mask 计算，不能从裁切或缩放后的输入计算。

区域对按分数降序做一对一贪心匹配；未匹配查询区域计零，按查询区域原始面积平方根加权平均。候选额外区域不直接扣分，因此交换查询与候选，分数可能不同。

## 数据与评价

Mixed-WM38 原始 38,015 条先按完整 0/1/2/3 像素精确去重，过滤 1,024 条冗余，保留 35,991 张缺陷图和 1,000 张 Normal。缺陷图按 37 种完整标签组合分层，seed=2026。

| 集合 | 图像数 | query 数 | 每个 query 的候选数 |
|---|---:|---:|---:|
| train | 25,193 | — | — |
| valid | 3,599 | 固定 500 | 3,598 |
| test | 7,199 | 全部 7,199 | 7,198 |

候选是同集合全部其他图像，排除自身；Normal 不入检索库。`sample_id` 保留原始 NPZ 行号。标签顺序为 center、donut、edge-loc、edge-ring、loc、near-full、scratch、random。冻结清单位于 `protocol/deduplicated/`、`protocol/retrieval_v1/`，加载时检查哈希，不重新抽样；文件职责见[协议说明](../protocol/README.md)。旧 2,000 query × 1,000 候选结果不能混用。去重保留同图的最小原始行 ID，同图标签冲突时报错。本项目的 8 份冻结协议文件与对比项目逐字节一致，各仓库可独立读取；旧训练集与新 valid/test 有重叠，旧协议 checkpoint、缓存和排名不能作为新协议正式结果。

**exact** 要求完整标签组合相同；**coverage** 衡量候选覆盖查询标签的比例；**FullCoverage** 要求覆盖全部查询标签，允许额外标签。它们评价同一排名，不是只选含两个标签的样本。

K=1、5、10、20、50、100、500，报告总体、类别宏平均、单/混合及标签数量分组。Recall/AP 分母和 coverage 的理想排名取完整候选库；只保存 Top-500，不能称为完整排名或 full mAP。跨组合评价另排除同标签组合候选，只报告 coverage，必须分表。公式、零分母规则统一见[对比项目的数据与评价](../../compared_methods/docs/项目说明.md#数据与评价)。

**exact 指标怎么算：** 设前 K 名命中数为 H，完整候选库的相关样本数为 R，第 r 名是否相关为 rel(r)。

| 指标 | 含义与公式 |
|---|---|
| Hit@K | 前 K 名至少命中一次：`1[H>0]` |
| Precision@K | 前 K 名命中比例：`H/K`；不足 K 的空位算未命中 |
| Recall@K | 找回全部相关样本的比例：`H/R` |
| AP@K / mAP@K | 单 query 为 `sum(Precision@r × rel(r), r≤K)/R`；再对 query 平均 |

AP 分母是 R，不是 `min(R,K)`。R=0 时 Recall/AP 不计入均值，Hit/Precision 仍参与；类别宏平均先算每个完整组合的均值，再给各组合相同权重。逐 query 输出叫 `AP@K`，汇总输出叫 `mAP@K`。

同分排序不看标签：固定 `tie_seed=2026`，对 `exact_v1:tie:{seed}:{query_id}:{candidate_id}` 求 SHA-256，以前 8 字节的大端整数排序，最后用原始 ID 兜底。它不随训练 seed 改变；实现见 [exact_metrics.py](../wbm_retrieval/exact_metrics.py)。

## 如何运行

使用已有 PyTorch/CUDA 环境，在仓库根目录运行。默认原始数据为 `../data/wm38k/Wafer_Map_Datasets.npz`；依赖见 `requirements.txt`，监督变体另见 `requirements-supervised.txt`。

当前 F 评价入口如下，来源模型必须已完成训练：

```text
python -u experiments/proposed/f_segmentation_geometry/run.py \
  --methods cc8 --splits test --device cuda --prepare-workers 4 \
  --output-root artifacts/<本次评价的时间型run_id>
```

尖括号是待替换项。删去 `--splits test` 会评价 valid 和 test；加 `--dry-run` 先检查运行计划。新实验先落实[保存与登记](#保存与登记)的时间身份要求，使用新目录；已有完成结果按原签名复用，不为整理文档重跑。六种分割训练见[分割入口](../experiments/proposed/f_segmentation/README.md)，其他实验参数看各自 README。

B1 组件消融使用独立 [b1_ablation](../b1_ablation/README.md)，复用冻结模型；来源与当前完成状态见[消融实验](消融实验.md#运行与来源)。F/G/WBBS三组固定融合使用独立[fgw_fusion入口](../fgw_fusion/README.md)，支持新的时间目录和签名一致的显式恢复。

独立[fgw_grid_search入口](../fgw_grid_search/README.md)已完成31项筛选与默认166项完整网格。完整运行使用`--stage search --config fgw_grid_search/config.json --workers 8`，仅评价valid，并按总体exact P@10冻结胜者。原`--stage test`入口仅接受冻结胜者。按用户追加要求，独立[前十项test入口](../fgw_topk_test/README.md)已用`python -u -m fgw_topk_test.run --search-root artificial/fgw_grid_20261119T200653+0800 --workers 8`完成原valid前十项的完整test，不改动旧搜索入口或选择记录。

独立[前十项跨组合入口](../fgw_cross_test/README.md)复用上述十组冻结配置及完整分项缓存，仅在检索前排除同标签组合候选，沿用原coverage指标。十项已在`artificial/fgw_cross_test_20261119T223644+0800/`完成，恢复和登记命令见专属README；详细结果与普通test分表保存在[消融实验](消融实验.md)。

独立[F与F×WBBS跨组合入口](../fw_cross_test/README.md)使用`python -u -m fw_cross_test.run --source-root artificial/fgw_topk_test_20261119T205138+0800 --workers 2`运行用户指定的两项固定公式。F沿用前十项的最优匹配组件，W采用同一原始分数；两项已在`artificial/fw_cross_test_20261120T104447+0800/`完成并通过独立核验，详细设计见[消融实验](消融实验.md#实验设计)。

独立[F与WBBS等权加法入口](../fw_add_cross_test/README.md)使用`python -u -m fw_add_cross_test.run --source-root artificial/fgw_topk_test_20261119T205138+0800 --workers 1`评价用户固定指定的`0.5F+0.5WBBS`，来源与指标同上述两项。该项已在`artificial/fw_add_cross_test_20261120T110737+0800/`完成并通过独立核验。

独立[F区域结构入口](../f_region_structure/README.md)已完成25项valid与唯一胜者test。使用`bash f_region_structure/launch_tmux.sh`启动隔离运行，或以`python -u -m f_region_structure.run --stage all --device cuda --prepare-workers 4`顺序执行训练、valid选优与冻结test；本轮目录为`artificial/f_region_structure_20261120T120331+0800/`。新增训练只涉及两个融合层，原CNN冻结，胜者本身无需新增训练。
