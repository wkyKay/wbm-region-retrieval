## 实验设计

主方法为 **F：cc8 八连通＋径向位置＋相对面积**。从原图缺陷像素提取八连通区域，去掉面积小于 5 的区域，最多保留最大的 4 个。以区域中心取固定 52×52 窗口，缩放到 96×96；三通道分别表示所有缺陷、目标区域和有效晶圆。

ResNet18 首层步长为 1，提取 h512；自监督 NCE 训练 100 epoch，seed=2026，投影维度 128，检索不用投影头。冻结使用 `best_nce`；训练有四种直角旋转，正式推断没有随机增强或四旋转平均。加入几何评分不重训、不重新选模。

```text
s = clip(cos(hq,hc),0,1) × exp(-D_radial)
    × (0.85 + 0.15 × exp(-D_area/1.5))
D_radial = sum(abs(CDFq-CDFc))/16
D_area = 0.5 × abs(log(rq/rc))
r = 区域原始缺陷像素数 / 有效晶圆像素数
```

径向项是归一化半径的 16 格累积分布，不是绝对二维坐标。有效晶圆取原像素值 1 或 2，中心取其包围框中心，半径取最远有效像素距离。全部几何量从完整原始 mask 计算，不能从裁切或缩放后的输入计算。

区域对按分数降序做一对一贪心匹配；未匹配查询区域计零，按查询区域原始面积平方根加权平均。候选额外区域不直接扣分，因此交换查询与候选，分数可能不同。

| 对照组 | 改什么 |
|---|---|
| cc8、cc4、median8、opening8、tv8、npfc_pre | 区域提取方式；cc8 是主方法，其余为对照 |
| F＋整图 WaPIRL | 局部与全局融合 |
| 占比、角向、最优匹配 | 几何约束或区域配对策略 |
| 角向＋最优匹配＋融合 | 查看上一轮 test 后提出的组合补充 |
| A～G、监督变体、旧 F | 早期系列，不当作当前 F 的同模型消融 |

实现和完整参数见[主方法说明](../experiments/proposed/f_segmentation_geometry/README.md)及[实验代码目录](../experiments/README.md)。

## 数据与评价

Mixed-WM38 原始 38,015 条先按完整 0/1/2/3 像素精确去重，过滤 1,024 条冗余，保留 35,991 张缺陷图和 1,000 张 Normal。缺陷图按 37 种完整标签组合分层，seed=2026。

| 集合 | 图像数 | query 数 | 每个 query 的候选数 |
|---|---:|---:|---:|
| train | 25,193 | — | — |
| valid | 3,599 | 固定 500 | 3,598 |
| test | 7,199 | 全部 7,199 | 7,198 |

候选是同集合全部其他图像，排除自身；Normal 不入检索库。`sample_id` 保留原始 NPZ 行号。标签顺序为 center、donut、edge-loc、edge-ring、loc、near-full、scratch、random。冻结清单位于 `protocol/deduplicated/`、`protocol/retrieval_v1/`，加载时检查哈希，不重新抽样；文件职责见[协议说明](../protocol/README.md)。旧 2,000 query × 1,000 候选结果不能混用。

**exact** 要求完整标签组合相同；**coverage** 衡量候选覆盖查询标签的比例；**FullCoverage** 要求覆盖全部查询标签，允许额外标签。它们评价同一排名，不是只选含两个标签的样本。

K=1、5、10、20、50、100、500，报告总体、类别宏平均、单/混合及标签数量分组。Recall/AP 分母和 coverage 的理想排名取完整候选库；只保存 Top-500，不能称为完整排名或 full mAP。跨组合评价另排除同标签组合候选，只报告 coverage，必须分表。公式、零分母规则统一见[对比项目的数据与评价](https://github.com/wkyKay/wbm-matching/blob/main/docs/项目说明.md#数据与评价)。

## 如何运行

使用已有 PyTorch/CUDA 环境，在仓库根目录运行。默认原始数据为 `../data/wm38k/Wafer_Map_Datasets.npz`；依赖见 `requirements.txt`，监督变体另见 `requirements-supervised.txt`。

当前 F 评价入口如下，来源模型必须已完成训练：

```text
python -u experiments/proposed/f_segmentation_geometry/run.py \
  --methods cc8 --splits test --device cuda --prepare-workers 4 \
  --output-root artifacts/<本次评价的时间型run_id>
```

尖括号是待替换项。删去 `--splits test` 会评价 valid 和 test；加 `--dry-run` 先检查运行计划。新实验先落实下节的时间身份登记要求，使用新目录；已有完成结果按原签名复用，不为整理文档重跑。六种分割训练见[分割入口](../experiments/proposed/f_segmentation/README.md)，其他实验参数看各自 README。

## 论文初稿

本文研究面向晶圆缺陷覆盖的有向检索：查询包含的缺陷应尽可能在候选中得到覆盖，候选可有额外缺陷。方法先提取局部区域，再结合自监督特征、径向位置和相对面积计算区域对分数，通过一对一匹配聚合为晶圆相似度。具体公式、训练设置和检索协议复用本页前述定义，避免出现两套方法描述。完整排版稿见 [LaTeX 源文件](PAPER_DRAFT_PROBLEM_METHODS.tex)，相关工作和文献表仍待补全。

对比方法共享数据与评价协议，保留各自表示，不强行共用区域提取。Yu、Nakazawa 使用监督分类，F、WaPIRL 使用自监督，其余三种无需训练；方法适配和未公开参数按对应 README 披露。coverage 是晶圆级标签评价，没有逐区域语义真值，不能据此宣称验证了区域语义对应。

融合 α=0.5、角向 γ=0.5 由 valid 的 exact 总体 Precision@10 选择，占比选择零强度。cc8 主方法身份在查看历史 test 后确认，组合也属于事后补充；不能声称全部方案在 test 前确定。自监督训练不等于研究过程不使用标签。结果以单种子为主，尚未证明跨种子稳定或差异显著；当前实现成绩也不等于原论文成绩。
