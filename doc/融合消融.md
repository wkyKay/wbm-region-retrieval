# 融合消融

记录 2026-11-14～15 完成的整图融合、单项消融与组合实验，2026-11-16 核对服务器原始报告。本文是这组实验的设计与结果摘要；公共运行及登记规则仍统一维护在[项目说明](项目说明.md)。

## 实验设计

目标是依次回答：整图能否补充局部？占比、角向、最优匹配哪个有用？有效单项叠加后是否继续改善？这是**已训练模型的分数融合**，没有重新训练或进行全局／局部联合训练。

局部分支 F 使用当前 **cc8＋径向位置＋相对面积**，checkpoint `89f1e6b3…`；整图分支 G 使用冻结 WaPIRL 的 h512 余弦，截断到 [0,1]。F 保留 min_area=5、Top-4、h512、单向贪心匹配及查询 sqrt(area) 权重。与[位置与尺度选择](history/20261116/主实验位置与尺度相似度选择.md)中旧 checkpoint `0085bd3b…` 的成绩分开看。

| 实验 | 只改变什么 | 选择规则 |
|---|---|---|
| 整图＋局部融合 | `B=(1−α)F+αG`，α 是整图权重 | valid 比较 0、0.1、0.2、0.3、0.5、0.75、1；test 只评选中值和两端点 |
| 整图缺陷占比 | `B × exp(−γ_d × abs(d_q−d_c))` | 固定 α=0.5，valid 比较 γ_d=0、2、5、10、20 |
| 外圈角向结构 | `B × exp(−γ_a × D_angle)` | 固定 α=0.5，valid 比较 γ_a=0、0.25、0.5、1、2 |
| 最优一对一匹配 | `0.5F_optimal+0.5G` | 保持区域对分数，替换贪心配对；无新增选参 |
| 角向＋最优匹配 | `(0.5F_optimal+0.5G) × exp(−0.5D_angle)` | 查看上一轮 test 后追加，仅 test，参数固定；属于事后补充 |

**占比** `d=整图原始缺陷像素数/有效晶圆像素数`，不是配对区域的相对面积，也不是 Top-4 面积之和。**角向**取完整原图中归一化半径 ≥0.65 的外圈缺陷，计算 1～4 阶圆周矩幅值：

```text
m_k = abs(mean(exp(i × k × θ)))，k=1,2,3,4
D_angle = mean_k(abs(m_k(q)−m_k(c)))
F_optimal = max_M sum_(i,j in M)(sqrt(area_i) × s_ij) / sum_i sqrt(area_i)
```

角向比较的是两图沿圆周分布是否相似，并非越集中越好；连续点集整体旋转不改变幅值，但像素旋转重采样不保证严格不变。任一图外圈无缺陷时距离记零。中心、半径沿用原径向定义；角向与占比项均作用于**整项融合分数**。最优匹配最多枚举 4!=24 种分配，未匹配查询区域记零，候选多余区域不额外扣分。

单项消融是在查看融合 test 后提出，再用 valid 选择强度；组合则在查看单项 test 后追加。各轮没有用 test 搜索参数，但不能把整个探索过程说成从未查看 test。

可调参数都按 valid **总体 exact Precision@10** 最大值确定，并列取较小参数；三个单项分别比较，不互相叠加。valid 为 500 query×3,598 候选，test 为 7,199×7,198，排除自身、使用冻结去重协议。每次对完整候选库打分，再保存 Top-500；exact/coverage 共用排名，分母仍取完整候选库。以下均为百分数，差值为百分点，valid/test 分表。

## valid 选择结果

整图权重按上述 7 个 α 顺序，P@10 分别为 39.72%、40.70%、41.96%、42.44%、42.82%、39.76%、29.62%，选中 **α=0.5**。随后固定 α，进行四组消融：

| 方案 | exact P@10（%） |
|---|---:|
| 原融合 α=0.5 | 42.8200 |
| ＋占比，γ_d=0（复用基线） | 42.8200 |
| ＋角向，γ_a=0.5 | 47.4600 |
| 改为最优匹配 | 42.9600 |

- 占比非零强度 2、5、10、20 的 P@10 为 41.88%、37.20%、33.02%、28.96%，均低于基线，因此选中 0。
- 角向强度 0.25、0.5、1、2 的 P@10 为 46.18%、47.46%、47.08%、44.56%，选中 0.5，较基线提高 4.64 个百分点。
- 最优匹配仅提高 0.14 个百分点，且 valid P@1 与部分 coverage 指标下降。选参用过的 valid 成绩不能视为独立泛化证据。

## test 结果与分组

| 方案 | exact P@10（%） | exact mAP@500（%） | Coverage-nDCG@10（%） |
|---|---:|---:|---:|
| 纯 F（cc8） | 46.1370 | 13.3147 | 82.4208 |
| 纯 WaPIRL | 34.5617 | 10.1188 | 72.8634 |
| 原融合 α=0.5／占比 γ_d=0 | 48.7123 | 15.4846 | 83.2032 |
| 融合＋角向 γ_a=0.5 | 54.2575 | 19.4941 | 85.8467 |
| 融合＋最优匹配 | 48.7971 | 15.6342 | 83.2057 |
| 融合＋角向＋最优匹配（事后补充） | 54.2770 | 19.6678 | 85.8737 |
| WBBS（同协议外部对照） | 58.1289 | 27.1098 | 87.8320 |

占比选中零强度，直接复用原融合排名，四组消融只有三套不同排名；没有测试其他占比强度。mAP@500 是截断指标，不是全排名 mAP。

| 查询分组，exact P@10（%） | 原融合 | ＋角向 | ＋最优匹配 | 角向＋最优匹配 | WBBS |
|---|---:|---:|---:|---:|---:|
| 单缺陷 | 69.8642 | 76.0114 | 70.6219 | 76.4832 | 80.8935 |
| 混合缺陷 | 43.6103 | 49.0103 | 43.5328 | 48.9207 | 52.6379 |
| 四标签 | 33.5125 | 37.0250 | 33.4875 | 37.1750 | 46.2125 |

角向使单、混合缺陷均改善；四标签组仍明显落后 WBBS。组合相对角向单项总体 P@10 只提高约 0.0194 个百分点：全部 71,990 个 Top10 返回位置净增加 14 个正确位置，其中单缺陷增加 66 个、混合缺陷减少 52 个。不能据总体微增声称最优匹配改善了混合缺陷检索，也不能从分组汇总断定某一具体组合的错误原因。

## 结论与限制

- **整图融合有效：** 相对纯 F，test P@10 提高约 2.58 个百分点；但 Coverage-nDCG@500 和 FullCoverage P@500 略降，非全指标提升。
- **角向是这轮收益最大的单项：** 相对原融合，test P@10 提高约 5.55 个百分点；总体主要指标仍低于 WBBS，部分 Hit 指标下降。
- **原始占比约束未通过本次 valid 选择；最优匹配收益很小。** 不能把 γ_d=0 的 test 复用解释成所有非零占比方案都在 test 失败。
- **组合只作补充证据：** 参数虽固定，但方案是在查看前一轮 test 后提出；未做跨训练 seed 重复或配对显著性检验。这组结果更支持保留“融合＋角向”作为扩展候选，不自动替换当前 cc8 主方法。
