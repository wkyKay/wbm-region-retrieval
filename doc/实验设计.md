# 实验设计

当前主方法是 **F：八连通 cc8＋径向位置＋相对面积**。融合和组合是扩展实验，不自动替换主方法。

## F 怎么检索

1. 从原图缺陷像素提取八连通区域，去掉小于 5 像素的区域，最多保留面积最大的 4 个。
2. 以区域中心取固定 52×52 窗口，再缩放到 96×96。三个通道分别表示所有缺陷、目标区域、有效晶圆。
3. ResNet18 提取 512 维特征；区域对同时比较形状、距晶圆中心的分布和相对面积。
4. 按区域对分数从高到低做一对一贪心匹配，未匹配查询区域计零；按查询区域原始面积的平方根加权汇总。因此交换查询与候选，分数可能不同。

固定的区域对分数为：

```text
s = clip(cos(hq,hc), 0, 1) × exp(-D_radial)
    × (0.85 + 0.15 × exp(-D_area/1.5))
D_radial = sum(abs(CDFq-CDFc)) / 16
D_area = 0.5 × abs(log(rq/rc))
r = 区域原始缺陷像素数 / 有效晶圆像素数
```

径向位置使用归一化半径的 16 格直方图，不是绝对二维坐标。几何量均从完整原始 mask 计算，不能从裁切或缩放后的输入计算。

训练使用 seed=2026、100 epoch 的自监督 NCE；固定使用 `best_nce`。检索使用 h512，不使用训练投影头。训练有四种直角旋转，当前正式推断没有随机增强或四旋转平均。加入位置和面积不重训，也不重新选 checkpoint。实现及参数见 [主方法说明](../experiments/proposed/f_segmentation_geometry/README.md)。

## 各组实验的作用

| 实验 | 要回答的问题 | 当前身份 |
|---|---|---|
| cc8、cc4、median8、opening8、tv8、npfc_pre | 换区域提取方式是否更好？ | 六组分割对照；cc8 为主方法 |
| F＋整图 WaPIRL | 局部和全局信息能否互补？ | 融合权重 α=0.5，由 valid 选择 |
| 占比、角向、最优匹配 | 增加约束或更换匹配是否有效？ | 占比选零强度；角向 γ=0.5；最优匹配单列 |
| 角向＋最优匹配＋融合 | 两个改动能否叠加？ | 查看上一轮 test 后提出的补充实验 |
| A～G、监督变体、旧 F 径向/面积 | 早期设计如何演进？ | 历史系列，不当作当前 F 的同模型消融 |

cc8 的主方法身份也是在查看历史 test 后确认的，不能写成全流程在 test 前确定。参数网格、代码和运行入口见 [实验目录](../experiments/README.md)，完成情况见 [实验结果](实验结果.md)。

新实验使用真实启动时间型 `run_id`，科学设置变化时写入新目录；登记与历史保护规则见 [AGENTS.md](../AGENTS.md)。
