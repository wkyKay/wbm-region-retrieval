# 径向 F＋相对面积与 WBBS：类别差距、错误类型和改进顺序

本分析仅使用已经完成的test排名、逐查询/逐类指标、原图和代码；未修改模型或评分逻辑，未重训、调参或重新运行检索。test诊断用于提出假设，后续方案与参数应回到train/valid选择。

核心结论：优先关注edge-loc及scratch相关类别。剩余差距不能只解释为候选多了缺陷：F的“既漏掉查询类别、又返回额外类别”的错型更多。低成本首项验证是整图缺陷占比约束；针对最大类别缺口，紧接着验证旋转不变角向结构与局部线状/块状结构。区域预算和训练目标后置，不应先把top4遗漏或窗口裁切认定为主因。

## 数据和比较口径

同一冻结test的7199个query，每query完整7198候选，37种完整multi-hot组合。F使用已固定的β=1、16-bin径向、面积σ=1.5/权重0.15。WBBS正式配置sigma_d=9、noise_threshold=0.32、alpha=5、mu=1、total_dies=2061；正式WBBS源码SHA与当前源码一致。

差距方向统一为WBBS−F。对完整组合类c，总体差距贡献定义为 (n_c/7199)×(WBBS_c−F_c)；37类贡献相加严格恢复总体差距。8标签条件分组相互重叠，只作定位，贡献份额不可相加。AP分母为完整候选库相关数，不用min(R,K)。

## 错误主要发生在哪一步

以下将两个方法所有Top10返回位置（71990个）按真实标签关系划分。百分比的分母是返回位置，不是query数量。

| 标签关系 | F | WBBS | F−WBBS（百分点） |
| --- | --- | --- | --- |
| 完整组合正确 | 46.05% | 58.13% | -12.08 |
| 查询类别齐全，仅多出类别 | 14.60% | 11.61% | +2.99 |
| 仅少了查询类别 | 11.94% | 16.09% | -4.15 |
| 部分重叠，同时少了与多了类别 | 23.90% | 12.91% | +10.98 |
| 没有共同类别 | 3.51% | 1.26% | +2.26 |

F的完整组合正确率比WBBS低12.08个百分点。额外类别型错误多2.99个百分点；同时缺失和额外的错型多10.98个百分点；纯缺失型反而少4.15个百分点。因此“多余候选区域不罚”是问题之一，但不是差距的完整解释。

在WBBS Top1正确而F错误的1869个query中，F有760个属于同时缺失和额外、589个仅多类别、386个仅少类别、134个完全无共同类别；F正确而WBBS错误也有1023个query。

### edge-loc：局部边缘与完整边缘环混淆

200个edge-loc查询的2000个Top10返回位置中，F返回纯edge-ring的比例为23.65%，WBBS为6.15%；F返回完全不含edge-loc的候选比例37.30%，WBBS为12.95%。这不仅是完整组合过严造成的差距，也损害类别覆盖。

径向直方图描述半径分布，但局部边缘弧段与完整圆环可能处于相似半径；面积只补总量。当前径向与面积项本身不显式描述角向集中程度或弧段覆盖。CNN有上下文并非没有这些信息，但现有分数没有充分分开这类候选，是可观察事实。角向统计能否解决，仍需valid消融。

### scratch：找到了划痕，但容易接受多出的其他结构

scratch查询Top10中，F完整组合正确67.70%，WBBS为93.35%；仅多出类别的候选占26.55%，WBBS为3.00%。其中loc+scratch占12.70%对1.55%，center+scratch占8.50%对0.10%。F的scratch Coverage-nDCG@10仍有0.946190，而exact mAP@100明显落后，说明这里的完整组合区分与深排名是重点。

F按查询区域的sqrt(area)归一化，不显式惩罚候选未匹配区域；当前面积门控只比较对应区域，乘子下限0.85，不等于整图缺陷量约束。WBBS则对去噪后整图点数差乘exp(-5|N−M|/2061)，并用相互最近邻点对。不能直接把其点数N/M替换为连通域数量。

### 全图缺陷负担的旁证

以原始缺陷像素数/有效晶圆面积定义占比。Top10候选与查询占比绝对差的平均值，F为0.022973（2.30个百分点），WBBS为0.010228（1.02个百分点）；F候选占比平均比查询高0.007415（0.74个百分点），WBBS接近零偏差。该观察支持检验全图负担约束，但相同占比也可能是不同类型，不能以此替代结构表达。

## 区域提取与裁切：有风险，但目前不能认定为主因

| 平均独立token数 | 3.96 |
| 合格CC超过4个的图 | 96.65% |
| 因min_area未成为独立token的像素比例（逐图平均） | 24.10% |
| 因top4未成为独立token的像素比例（逐图平均） | 13.48% |
| 独立token遗漏合计（逐图平均） | 37.58% |
| 至少一个context窗口可见的缺陷像素比例（逐图平均） | 99.72% |
| 目标裁切像素/已选像素（逐图平均） | 1.63% |

没有独立token不等于CNN看不到：第一通道含窗口内所有缺陷，多个token的context并集保留绝大多数缺陷。几何统计不能证明被过滤的是语义缺陷还是噪声，也不能在没有像素类别标注时证明一个CC合并了哪几类。独立token遗漏比例与AP10的整体Spearman仅约+0.083，类别混杂明显；裁切比例与AP10约−0.099。故不能把增大窗口、top4改成全部区域当成已经找到的答案。

## 建议的改进顺序

1. **先验证整图缺陷占比软约束，成本最低。** 冻结现有区域、h512、径向和面积设置，在整图分数乘exp(-γ|d_q−d_c|)，d为全图缺陷像素占比。γ=0严格回退当前基线；γ只在valid确定。可另作独立版本使用明确去噪后的全图占比，但不要把两种定义混成一次修改。这主要检验scratch多余结构及整体负担失配，不承诺解决相同密度的错型。
2. **优先研究旋转不变角向结构，针对最大的edge-loc缺口。** 用全部原始缺陷或一致去噪点集，在外侧径向带计算角向密度的圆周Fourier幅值/集中度；按总质量归一化，避免重复计算面积。直接圆周矩的幅值具有整体旋转不变性，先分箱再做离散FFT对任意角度旋转一般只有近似不变性。不要加固定方位角惩罚，也不要仅用“有一个点即占据”的噪声敏感统计。
3. **与角向项独立对照局部结构描述。** 借鉴WBBS的stick/ball与半径联合统计，区分线状、块状、局部密度；先补固定统计量，不重训CNN、不直接混入完整WBBS分数。若有增益，再考虑作为输入通道或联合学习目标。
4. **随后再改区域预算和训练。** 比较top4/top8、残余区域汇总描述等；不要直接降低min_area并加入全部碎片。新token分布与原训练top4不同，须单独验证。更后面再研究区域/全图联合学习及NCE潜在假负例，不能把同图的不同缺陷区域一律设为正例。

首轮valid建议保留清晰的单项比较：现基线、＋全图负担、＋角向结构、＋stick/ball结构；单项有效后再组合。既有双向平均、rot4在径向基础上的增益较小且区间跨零，故不作为当前首要方向；它们也未在此面积版本上完成新的消融。

完整组合检索会惩罚额外类别，但coverage允许候选有额外类别。全图负担或未匹配惩罚可能改善exact同时损伤coverage，必须同时观察两组指标、mixed表现及上述保留优势类。test本轮诊断不能变成继续在test上选权重。
