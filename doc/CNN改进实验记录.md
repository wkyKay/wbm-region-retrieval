## 1．问题、共同基线与判断标准

前两轮分别回答：减少非目标上下文依赖、过滤可能的假负例能否改善区域表示；将原直角旋转换成其他增强能否改善检索。第三轮进一步检验旋转CNN是否需要调整融合权重。当前证据是**第一轮两个方案均未达到预设检索目标；第二轮只有任意角旋转达到目标；第三轮新权重提高跨组合覆盖，但降低普通exact P@10和mAP@100**，具体负结果和指标取舍见下文。

| 项目 | 前两轮共同设置 |
|---|---|
| 数据 | MixedWM38原图精确去重后的冻结划分：train 25,193／valid 3,599／test 7,199；原始sample_id不重新编号，Normal不进入缺陷检索库 |
| 检索池 | valid固定500个query、完整3,599张图库；test全部7,199个query、完整7,199张图库；普通检索均排除自身 |
| 原基线 | `artifacts/f_segmentation_v1/cc8/`的seed=2026、`best_nce`，实际为第100轮；直接复用已有模型及可复用评价 |
| 新模型训练 | 从原seed=2026相同初始化开始；三通道ResNet18、原52→96固定窗口、GAP、h512／z128、NCE、SGD、memory bank、batch=256、每次5,000个有放回负例；每模型100轮／39,000步 |
| 模型选择 | 新模型统一固定取第100轮；不是从已有100轮模型继续微调，不按valid或test重新选epoch；valid共同旋转NCE仅作诊断 |
| 固定检索部件 | cc8、min_area=5、Top-4区域、原几何量、单向贪心一对一及查询区域`sqrt(area)`聚合；仅替换深度分支使用的模型 |
| 训练标签 | 新模型训练、教师邻居图构建均不使用类别标签；评价及部分诊断使用标签 |

两条评分路线均保留：

```text
CNN单独评分：C = clip(cos(h_q, h_c), 0, 1)
前两轮固定融合：S = 0.75 × (0.4 × C + 0.6 × T) + 0.25 × A
               = 0.30 × C + 0.45 × T + 0.25 × A
```

其中T为形态—径向联合结构相似度，A为相对面积相似度。前两轮“融合”均指当时的论文配方，不是当前新权重或历史F的径向／面积乘法评分；前两轮未重新调融合权重，第三轮配权范围另见第5节。

普通检索的exact相关性要求完整标签组合相同，coverage使用查询标签覆盖比例；两者使用同一排名。跨组合检索先排除与query完整标签组合相同的候选，再从全部剩余候选得分重新排序，只报告coverage；它不是未见训练组合泛化实验。FullCoverage允许候选含额外标签，但必须覆盖query全部标签。AP／Recall分母和nDCG的IDCG按对应完整候选池计算，mAP@100不是完整排名mAP。两轮均保留K=1／5／10／20／50／100／500、总体、完整组合宏平均、单／混合、标签数量及逐类／逐query报告。

前两轮预设检索标准为：固定融合普通test exact P@10至少提高1个百分点，且配对95%差值区间下界大于0；跨组合Coverage-nDCG@10差值区间下界高于−0.5个百分点。若声称CNN表示改善，还须CNN单独检索改善。上下文方案另要求drop50与dropall的h512距离均降低至少30%，并结合近邻质量、方差与有效秩判断。所有预设方案均完成评价，不按成绩淘汰；第三轮仅按valid冻结唯一权重，再报告其test差值，不套用该训练改进判据。

## 2．第一轮：上下文删除与无标签负例过滤

目的来自两项诊断假设：区域编码器可能依赖窗口中的非目标缺陷；无标签NCE可能把语义相近区域当成负例。两个方案独立训练。

| 方案 | 实际操作 | 保持不变的部分 |
|---|---|---|
| 上下文删除 `context_dropout` | 第二视图在原52×52窗口中，对非目标缺陷像素逐像素以0.5概率删除，然后resize并执行原直角旋转 | 第一视图和检索仍用完整原窗口；不删除窗口中已有的目标像素，目标mask及有效晶圆支持不变；正／负例定义不变 |
| 无标签负例过滤 `filtered_negatives` | 用冻结旧基线提取train区域原图／90°旋转两视图的h512；跨晶圆穷举余弦Top-500，在两视图中均为双向互近邻的区域形成固定排除图；原负例抽样命中该图时补抽，保持每次5,000个负例 | 输入仍为原增强；不使用类别标签或valid/test特征建图，不增加正例、不直接拉近伪邻居；保留原批内排除规则，不额外排除所有同晶圆负例 |

**两种改进并不都是更换增强方式。** 上下文删除改的是第二视图的输入增强；负例过滤改的是对比学习负例采样，原输入增强仍保留。两者都没有改CNN架构，也未组合训练。

结果解释：上下文组在共同valid区域上的drop50／dropall距离分别降低87.01%／33.90%，但单标签代表区域的类均衡近邻质量下降，test检索也下降。减少上下文敏感性没有转化为更好的检索表示；非目标上下文还可能包含同一缺陷的其他片段，不能把全部上下文都视为无用噪声。

负例过滤在100轮中实际替换136,269,374／49,893,000,000个原负例槽位，约0.27312%。在两端都来自单标签晶圆的可判定图边上，标签代理precision为56.60%、recall为2.29%；这些边仅占整图7.65%，不是全图真实语义精度。独立抽样诊断显示，在冻结教师h512空间中，anchor与被替换负例的平均余弦为0.942710，anchor与补入负例为0.834807，说明过滤也改变了教师相似性所度量的负例难度，无法归因为纯粹消除假负例。

因此，第一轮两个方案均未达到预设检索目标；这不证明上下文学习或假负例处理普遍无效，也不能据此断言CNN无用。仍保留正向指标：两组普通融合FullCoverage mAP@100均提高，跨组合FullCoverage Hit@10也提高；这些并未替代预设主判据。详细诊断及指标见[第16节](消融实验.md#cnn-refinement)，操作和恢复入口见[实验README](../cnn_refinement/README.md)。

## 3．第二轮：论文中的五种单独输入增强

依据Kahng与Kim（2021）《Self-Supervised Representation Learning for Wafer Bin Map Defect Pattern Classification》及作者固定版本代码。原文ResNet18分类表中，裁剪在六档标注比例的四档最佳，旋转在另外两档最佳；该表含有监督微调，不能直接视为当前无标签区域检索的结论。原PDF哈希、表II数值及作者代码版本见[来源记录](../cnn_augmentation/paper_source.json)。

五种操作分别替换原第二视图的直角旋转，互不叠加，也不叠加第一轮两种改进。第一视图和检索仍用完整原窗口，所有操作均适配到已有96×96三通道缓存。

| 单独增强 | 本轮固定参数与处理 |
|---|---|
| 随机裁剪 | 面积比例0.5–1.0、宽高比0.9–1.1，三通道同步裁剪，以nearest恢复96×96 |
| Cutout | 以0.5概率应用4个边长19的孔，三通道同孔填0；孔可重叠，边界截断 |
| 像素噪声 | 有效晶圆内以0.05概率选像素，再等概率设为正常／缺陷，实际变值率约2.5%；目标通道取原目标与新缺陷的交集，晶圆支持不变 |
| 任意角旋转 | 角度均匀取−180°至180°，三通道同步，nearest、边界填0；与原90°倍数旋转不同 |
| 随机平移 | 每轴均匀±25%边长，三通道同步，nearest、边界填0，不额外旋转或缩放 |

没有依据目标保留率重抽、拒绝或恢复视图。每模型100轮累计生成9,978,600个第二视图，只有Cutout出现空目标，比例为0.7893%。任意角旋转的目标源像素平均保留率为91.3934%，仍取得最好的预设检索表现，说明不能用保留率单独解释成败。这里的源像素来自96×96缓存，不是原始die计数；该流程是作者增强操作的区域检索适配，不是原文分类结果复现。

结论：任意角旋转改善CNN单独评分与固定融合的主要检索目标；裁剪只改善部分前排指标，平移的CNN收益未转化为融合P@10收益，Cutout和噪声作为单独替换方案在当前设置下退步。具体参数及实现边界见[实验README](../cnn_augmentation/README.md)，完整结果见[第17节](消融实验.md#cnn-augmentation)。

## 5．第三轮：任意角旋转CNN的融合权重搜索

本轮回答：第二轮的任意角旋转已经改善了C，重新调整C、T、A的比例能否进一步改善融合检索？复用第二轮冻结的第100轮旋转模型及原始视图h512特征，原CNN仍使用既有`best_nce`第100轮；没有重新训练、提取特征或选择checkpoint。

**搜索范围与选择。** 区域对评分为：

```text
S(α, β) = (1−β) × [αC + (1−α)T] + βA
α ∈ {0.4, 0.5, 0.6}
β ∈ {0.05, 0.10, 0.15, 0.25}
```

只比较上述12组原有加法权重。固定cc8、min_area=5、Top-4、原始区域描述、贪心一对一匹配与查询sqrt(area)聚合；逐区域对重新融合、匹配和排序。T仍先在全图计算张量投票与通道归一化，再用区域mask内全部原始缺陷点构建128维形态—径向联合分布，计算`exp(−0.5×Hellinger)`；A仍为原相对面积相似度。CNN改进只改变C，配权阶段另改变外层系数。

仅按500个固定valid query的exact Top-10整数命中总数选择唯一θ*；并列优先原权重，再按配置名称字典序。2026-11-24 09:40:26冻结`α=0.4, β=0.15`：

```text
原权重 θ₀：0.30C + 0.45T + 0.25A
新权重 θ*：0.34C + 0.51T + 0.15A
```

旋转CNN在valid上的P@10由原权重的53.06%（2,653／5,000次命中）变为53.48%（2,674／5,000次命中）。C:T内部比例仍为4:6，主要调整是面积权重从25%降至15%；这不是增大CNN相对结构分支的占比。选择依据见[selection.json](../results/20261124T093446+0800__cnn_rotation_fusion/selection.json)与[12组valid表](../results/20261124T093446+0800__cnn_rotation_fusion/report/valid_selection.csv)。test及WBBS成绩不参与权重选择。

**四角色与WBBS对照。** 原／旋转CNN分别配θ₀和θ*，用于区分更换编码器与调整权重的效果；原CNN的θ*是同权重控制，不是为原CNN重新选出的最优配方。已有相同模型、权重及协议的结果沿用原key，WBBS引用正式历史来源，不重复登记。

本轮是在观察既往test后提出的单seed事后研究。valid选参不消除此前对test的接触；条件区间不包含训练seed方差，也未校正既往探索或多重比较。若只以普通exact P@10为目标，结果不支持将新权重称为进一步改善；跨组合覆盖收益须分别报告。用户于2026-11-24查看这些结果后指定旋转CNN＋新权重为当前主方法，这是明确的方案采用决定，不是test前选型，也不将新方案表述为全指标最优。完整解释见[消融实验第18节](消融实验.md#cnn-rotation-fusion)。
