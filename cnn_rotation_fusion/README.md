# 任意角旋转CNN的加法融合配权

本实验按用户2026-11-24要求，复用已完成的任意角旋转CNN，比较12组原有加法融合权重，并将选定方案与同协议WBBS比较。旧模型、来源缓存及历史结果只读；不新增训练，不扩大参数范围。公共协议见[项目说明](../doc/项目说明.md)，论文证据状态见[证据总表](../doc/论文实验证据总表.md)。

## 固定来源与参数

原CNN为`artifacts/f_segmentation_v1/cc8/`的seed=2026、`best_nce`第100轮。旋转CNN来自`results/20261123T211208+0800__cnn_augmentation/training/rotation/checkpoint.pt`，固定第100轮；直接读取该运行`features/rotation/<valid|test>/original.npy`，验证模型、特征、区域行序及冻结数据来源。

```text
S(alpha,beta) = (1-beta) * [alpha*C + (1-alpha)*T] + beta*A
alpha = 0.4, 0.5, 0.6
beta  = 0.05, 0.10, 0.15, 0.25
theta0 = (0.4, 0.25)，即0.30*C + 0.45*T + 0.25*A
```

C为截断到[0,1]的h512余弦，T为原形态—径向联合结构相似度，A为原相对面积相似度。保持cc8、min_area=5、Top-4、原始mask几何量、单向贪心一对一及查询`sqrt(area)`聚合。每个配方在区域对层面重新组合、匹配和排序；不能线性组合旧整图分数、排名或检索指标。

## 选择与对照

普通valid固定500个query、完整3,599张图库，排除自身；新CNN的12组全部完成后，仅按exact Top-10整数命中总数选择一个方案。并列时优先theta0，再按配方名称字典序。选择规则、网格和来源在评价前冻结；不使用test或WBBS成绩选权重。旧CNN对应12组valid结果核验后引用，保留原身份。

选择冻结后比较以下四个角色：

| 编码器 | 原权重theta0 | 新CNN在valid选出的theta* |
|---|---|---|
| 原CNN | 原主方法 | 单独改权重的对照 |
| 任意角旋转CNN | 已完成的固定融合改进 | 新CNN与新权重 |

相同角色或已完成配置引用原key，不重复登记。theta*=theta0时明确标为同一结果。test使用全部7,199个query、每query完整7,198个非自身候选；跨组合先排除相同完整标签组合再排名，保留完整池分母。所有评价保留K=1/5/10/20/50/100/500、总体、完整组合宏平均、单／混合、标签数量、逐类及逐query报告；普通exact／coverage同排名，跨组合只报告coverage。

WBBS使用中央登记中的`wbbs_test`与`cross_wbbs`原始来源，核验协议、报告及排名绑定后引用，不重跑或重复登记。最终比较表同时列普通和跨组合指标，各列清楚标明协议，避免合并不同候选规则。必要的配对区间只对相同query、完整标签与候选池，按组合内重采样计算；旧报告的类别编码差异须验证后在报告内标准化，不改原CSV。

## 执行与核验

正式运行使用实际时间分配的`results/YYYYMMDDTHHMMSS+0800__cnn_rotation_fusion/`独立目录。各新增评价分别持久化真实开始时间、身份、来源签名和完成标记；改变科学设置使用新运行，禁止改写旧实验签名。已有科学结果一致时复用，失败或未完成阶段不能纳入正式表。

入口及恢复参数以`python -m cnn_rotation_fusion.run --help`为准。阶段顺序为冻结初始化、12组valid、唯一选择、必要对照与test、比较报告、封存；完成后由`python -m cnn_rotation_fusion.register --run-root <实际目录> --apply`登记新增评价，再执行公共`collect/check`及两套归档核验。

验证分别覆盖原模型／特征／协议绑定、每个新配方的独立区域公式与贪心抽查、完整候选排序与指标分母、所有K与分组重算、完整选择与重复引用身份，以及原登记对象保护。写作表和区间绑定原始报告，不手工改数；本地写作子集与服务器完整科学归档分别说明。

## 解释边界与状态

这是观察已有任意角旋转test结果后提出的事后配权研究。valid选参约束后续搜索，但不能把现有test重新称作未接触的独立确认集。单seed和固定图库条件配对区间不代表训练稳定性，也未校正既往探索或多重比较。新结果不自动替换原论文主模型，是否入稿由证据总表单独维护。
